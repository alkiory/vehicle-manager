# Vehicle Manager

Native Android vehicle tracking application built with Kotlin, Jetpack Compose, Material 3, Hilt, Room, KSP, Coroutines, and Flow.

## Current status

The project foundation from `instructions.md` TASK-001 is in place:

- Android application module targeting SDK 35 with min SDK 26.
- Java and Kotlin compilation target JDK 21; a complete JDK installation is required for builds.
- Kotlin 2.0 and Compose compiler plugin.
- Version catalog in `gradle/libs.versions.toml`.
- Hilt application and activity entry points.
- Room and KSP configuration with schema output at `app/schemas`.
- Core and feature package skeletons.

The remaining epics will be implemented incrementally in the order defined by `instructions.md`.
